# Tasks

The groups are headings for reading. Each task names the narrowest check
that shows it done, run as written; no task runs the repository's whole
checks or a group's, which the change's verify stage and the merge queue
run (record 0054). Each task leaves every crate and its tests building,
as the pre-commit hook's clippy over every target asks, so a task that
changes a type or a trait builds every use of it. `<base>` is written as
is, for the branch the place running it was cut from and lands on. The
statement is read at boomdrivedev/blueprints 48a94da (170, 172, 197,
C.4, C.5, S75); record 0026 and rules core.30 and core.39 hold the
outcome. Design sections are this change's `design.md`.
