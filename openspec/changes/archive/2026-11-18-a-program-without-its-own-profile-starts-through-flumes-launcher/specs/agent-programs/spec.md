## MODIFIED Requirements

### Requirement: The common profile's command

The common profile SHALL run the program the settings name, by name
or path, in the place, through flume's launcher, the binary that builds
the command by its absolute path with `ack launched --`: with its
entry's flag for each setting given where the entry names one, the
account's environment with the four `FLUME_*` words over it, its
entry's kind, and no prompt argument, folder-trust answer or file; its
stop-short SHALL name that binary by its absolute path (88, 92, 170,
171, C.4; core.60).

#### Scenario: amp's command

- **WHEN** the common profile over amp's entry gives the command for a start under an account giving `AMP_HOME`, with no model, effort or mode
- **THEN** it runs `amp` with no arguments through the launcher, the binary by its absolute path with `ack launched --`, the kind `amp`, `AMP_HOME` and the four `FLUME_*` words, and its stop-short names the binary by its absolute path (88, 92, C.4)

### Requirement: The common profile answers the seam's defaults

Each part of the agent seam the common profile reads nothing of SHALL
answer as the seam's default: received, asking, own work, ended,
spent, windows and live unknown; last words and conversation none;
send-back, on-quiet, guard, carry and the mode read back not offered;
no reserved key; and own settings refused where any are given (93,
170, 171, 195).

#### Scenario: Nothing read of amp

- **WHEN** the common profile over amp's entry is asked each reading of an agent it started but its start's
- **THEN** each answers the seam's default, and its own settings `{ "x": 1 }` are refused (93, 195)

## ADDED Requirements

### Requirement: The common profile reads its start from the launcher's word

The common profile SHALL say it starts its program through the
launcher, and SHALL read, from the launcher's word in the place's own
folder, that the agent started once the word says nothing differed,
how it began otherwise where the word says something did, and the
process the word names; not started before a word, and unknown where
the folder cannot be read (35, 161, 171, C.4).

#### Scenario: amp's start read from the launcher's word

- **WHEN** the common profile over amp's entry reads a start with no word, then with a word naming the process 41 and nothing differing, then with one naming `AMP_HOME` with another value, then in a folder it cannot read
- **THEN** it reads not started and no process; started in 41 and begun as recorded; not started, begun with another `AMP_HOME`, in 41; and unknown, with neither a process nor a way it began (35, 161, C.4)
