# Tasks

The groups are headings for reading. Each task names the narrowest check
that shows it done, run as written; no task runs the repository's whole
checks or a group's, which the change's verify stage and the merge
queue run (record 0054). Each task leaves every crate and its tests
building, as the pre-commit hook's clippy over every target asks, so a
task that changes a type builds every use of it. `<base>` is written as
is, for the branch the place running it was cut from and lands on. The
statement is read at boomdrivedev/blueprints 3a3b287 (4, 56, 130, 175 to
178, C.2); record 0079 holds the choices. Design sections are this
change's `design.md`. Each new engine scenario goes in
`crates/flume-conformance/src/engine/statecharts.rs`, registered in
`engine/mod.rs` both as a module and in `scenarios()`, unless the task
names another file, and cites the clauses its spec scenario cites.
