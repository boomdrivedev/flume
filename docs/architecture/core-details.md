# flume rules: details

Each rule of `core.md`, the page beside this one, in detail: what it
rules out, what it leaves open, and its sources. `core.md` binds; a
detail here reads its rule and never widens or narrows it. This page
loads when a file under `docs/architecture/` is read, so a session
that reads or changes a rule has its details and every other session
loads `core.md` alone (core.61). A rule's details are amended here in
the same commit as the rule.
